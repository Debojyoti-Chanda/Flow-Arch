# Quick Start Guide

## Setup Virtual Env and Activate it
```bash
python -m venv .venv
```

```bash
source .venv/bin/activate
```


## Get Started in 3 Steps:

### 1. Install Flask
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
python app.py
```

### 3. Open in Browser
Navigate to: http://localhost:5000

---

## What You'll See:

🏢 **Organization Mind Map** with beautiful gradients:
- Purple = Organizations (IFS, IFS UK, etc.)
- Pink = Teams (HHD, SAS, XYZ, etc.)
- Blue = Flows (Flow 1, Flow 2, etc.)
- Green = Applications (Hiport, IHub, JHI, etc.)

---

## How to Use:

1. **Click** any node to expand/collapse it
2. Use **"Show Search"** to search for applications
3. Type an app name like "Hiport" or "IHub"
4. Matching apps will highlight and auto-expand
5. Use **Expand All** / **Collapse All** for quick navigation

---

## Customize Your Data:

Edit these JSON files:
- `organizations.json` - Your organization structure
- `flows.json` - Your application flows

Then refresh the browser!
